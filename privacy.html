Privacy policy

Invisibles browser extension and web app · last updated 20 November 2026

The short version

Invisibles does not collect pasted text, does not upload it, and does not use analytics. There is no server and no account. The text you paste exists only in the open page or side panel while you are using it; it is not saved to disk as content.

The extension may remember a few UI choices via chrome.storage.sync: whether you dismissed the first-run hint, whether punctuation normalizing is on, and whether clean-on-paste and clean-on-copy are on. It may also remember a number in chrome.storage.local: how many hidden characters Clean has removed on this browser. Those values are not your text. The web app does not use any browser storage APIs.

What data is collected

None. Nothing is gathered, retained, transmitted or sold. Invisibles never collects, transmits or sells:

  • personally identifiable information
  • health, financial or authentication information
  • personal communications, including the text you paste in
  • location, browsing history or web activity
  • usage analytics, crash reports or telemetry

How it works instead

You paste text into a box. The script scans that string for characters in its table, marks where they sit, and builds a cleaned copy. All of that happens in the page you have open, in your own browser, using ordinary JavaScript on a variable in memory. The cleaned result stays in the same panel until you close it or replace it; it is not uploaded.

Closing the tab or panel clears pasted content from memory. That is separate from the extension UI preferences below, which Chrome may sync with your profile if you use the extension.

Storage

Pasted text: not stored. Invisibles does not write your input to localStorage, sessionStorage, cookies, IndexedDB, or any server.

Extension UI only: the Chrome build uses chrome.storage.sync (with chrome.storage.local as a fallback if sync is unavailable) for four booleans: whether the first-run hint was dismissed, whether punctuation normalizing is on, and whether clean-on-paste and clean-on-copy are on. Existing installs keep the first two keys (hintDismissed and normalizePunct); the two new switches default to off. chrome.storage.local also stores removedTotal, a count of hidden characters cleaned on this browser. No strings from your paste are included. The toolbar badge is the current count in the open panel, and it is not saved. The web app at cig13zs.github.io/invisibles does not call chrome.storage or localStorage. You can verify this in the public source: search for chrome.storage in extension/popup.js.

Permissions

The extension declares sidePanel and storage.

  • sidePanel — opens Invisibles beside the current tab when you click its toolbar icon.
  • storage — saves the UI preferences above and the cleaned-character count; not your pasted text.

The extension declares no host_permissions, so it cannot read the pages you visit. It has no access to your tabs, history, cookies or files.

Chrome Web Store Limited Use

Invisibles' use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. The extension does not collect, transfer, sell or use Chrome API data for advertising, credit decisions or any purpose unrelated to its visible text-cleaning feature.

Network access

The text-processing code makes no network requests. It contains no remote code, no third-party libraries, no fonts loaded from elsewhere and no tracking scripts. The GitHub and Ko-fi links open those sites only after you click them; pasted text is never included in either navigation.

The same is true of the web app at cig13zs.github.io/invisibles, which is one HTML file and one script. GitHub serves that page and will see the request for it in the way any web server sees a request, which is covered by GitHub's privacy statement. Nothing you paste into the page is part of that.

Reporting a miss

There is a "Report a miss" link in the side panel, for when a hidden character slips past or something gets flagged that should have been left alone. It does nothing until you press it. When you do, it builds a short note, copies it to your clipboard and opens a pre-filled GitHub issue so you can read it, edit it and decide whether to submit it.

Your text is not in that note. It contains the code points that were flagged (for example "U+200B Zero-Width Space x3"), the length of what you pasted, and how many of those characters were non-ASCII. That is enough to add a missing rule and useless to anyone reading it as content. Nothing is gathered in the background and nothing is ever sent on its own.

Third parties

No data is shared with third parties, because none is collected. Invisibles is not affiliated with, endorsed by or connected to OpenAI or any other AI provider.

What it does not claim

Invisibles removes invisible characters. That is not the same as removing an AI watermark: the statistical patterns in word choice and sentence structure are a separate thing, and no character cleaner touches them. If a tool tells you otherwise, it is overselling.

Changes

If this policy changes, the updated version appears at this address and the date above changes. The source is public, so any change in behaviour is visible in the commit history.
